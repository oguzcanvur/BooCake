# BooCake

CENG361 dersi için geliştirilen oyun projesi: canavarlara cupcake satan bir dükkân (tarayıcıda, sadece fare ile).

Proje kararları ve ortak notlar için bkz. [CLAUDE.md](CLAUDE.md). Tasarım: [docs/game-design.md](docs/game-design.md), plan: [docs/production-plan.md](docs/production-plan.md).

## Çalıştırma
Node.js gerekir. Proje klasöründe:

```
npm install
npm run dev
```

Sonra tarayıcıda http://localhost:5173 adresini aç.

Yayın build'i için `npm run build` (çıktı `dist/` klasörüne gider).
